Instalação
Aviso do Windows?
Normal! O Windows bloqueia programas novos por padrão. Siga os passos abaixo para executar.
1

Baixe o arquivo normalmente

Clique em Baixar Grátis. O navegador pode perguntar se deseja manter o arquivo — clique em Manter ou Keep anyway.

2

Tela azul do SmartScreen

Se aparecer a tela azul "O Windows protegeu seu PC", clique em Mais informações (o link pequeno abaixo do texto).

3

Clique em "Executar assim mesmo"

Após clicar em "Mais informações", aparece o botão Executar assim mesmo. Clique nele e o painel abrirá normalmente.

✓

Por que isso acontece?

O Windows SmartScreen bloqueia qualquer programa novo sem certificado digital. O painel é 100% seguro — o código é aberto e está disponível no GitHub para quem quiser verificar.
